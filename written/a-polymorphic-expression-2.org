Recall that the type ~('a, 'b) result~ is defined as follows.
#+begin_src ocaml
  type ('a, 'b) result =
    | Ok of 'a
    | Error of 'b
#+end_src

Determine an OCaml expression with the following polymorphic type.
#+begin_src ocaml
  ('a -> 'b) -> ('c -> 'a, 'b) result -> 'c -> 'b
#+end_src
Your expression may not include ~assert false~ or recursion.
