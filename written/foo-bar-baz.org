Consider the following function.
#+begin_src ocaml
  let do_thing (s : 'a stuff) (x : int) =
    match s with
    | Foo f -> f x
    | Bar (y, z) -> (if y then y else y) :: z
    | Baz l -> l.first (l.second (l.third = x))
#+end_src

Determine the *smallest* type ~stuff~ such that ~do_thing~ is
well-typed.
