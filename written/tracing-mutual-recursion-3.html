Tracing Mutual Recursion (3)

Consider the following pair of functions. 

let rec foo l =
  match l with
  | [] -> []
  | false :: bs ->
    List.map (fun x -> x - 1) (0 :: foo bs)
  | true :: bs -> bar l
and bar l =
  match l with
  | [] -> []
  | false :: bs -> foo l
  | true :: bs -> List.map ((+) 1) (0 :: bar bs)
  1. What is the type of foo?
  2. What is the value of the following expression? foo [true;true;true;false;false;false;false;true;true;false]
