Tracing Mutual Recursion (2)

Consider the following OCaml function. 

let f =
  let rec g lst =
    match lst with
    | true :: false :: xs -> 1 + k xs
    | _ -> 0
  and h lst =
    match lst with
    | true :: xs -> 1 + k xs
    | _ -> 0
  and k lst = max (g lst) (h lst)
  in k
  1. What is the type of f?
  2. Evaluate the following expressions.
    • f []
    • f [true]
    • f [true;false]
    • f [false;true;true;false]
    • f [true;true;true;false;true]
