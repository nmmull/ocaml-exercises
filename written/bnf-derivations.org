Consider the following BNF grammar.

#+begin_src bnf
  <prog>  ::= <stmts>
  <stmts> ::= <stmt> | <stmt> <stmts>
  <stmt>  ::= let <var> = <val>
  <var>   ::= x | <var> '
  <val>   ::= <var> | fun <var> -> <val> | ( <val> <val> )
#+end_src

Give a parse tree for the sentence

#+begin_src
  let x = fun x -> x
  let x' = (x x)
#+end_src
