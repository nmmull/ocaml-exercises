If-Then-Else Expressions

<e>  ::= if <e> then <e> else <e> | <e> + <e2> | <e2>
<e2> ::= true | false | 1 | ( <e> )
  1. Demonstrate that the sentence if true then 1 + 1 else 1 is recognized by the above grammar by providing a parse tree for it.
  2. Demonstrate that the above grammar is ambiguous by determining a sentence which has multiple parse trees. Include both parse trees in your solution.
