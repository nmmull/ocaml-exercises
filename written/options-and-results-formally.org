The following are the syntax, typing, and semantic rules for options
with a simple form of pattern matching.

*Syntax:*

#+begin_src bnf
  <ty>   ::= <ty> option
  <expr> ::= None | Some <expr>
           | match <expr> with None -> <expr> | Some <var> -> <expr>
#+end_src

Note: the ~|~ separating the ~None~ and ~Some~ branches in the
~match~ production above is part of the expression syntax itself,
not a BNF alternative — ~<expr>~ has exactly three top-level
productions (~None~, ~Some <expr>~, and the ~match~ form).

*Typing:*

\[
\dfrac{}{\Gamma \vdash \texttt{None} : \tau\ \texttt{option}}\ (\text{None})
\]
\[
\dfrac{\Gamma \vdash e : \tau}{\Gamma \vdash \texttt{Some}\ e : \tau\ \texttt{option}}\ (\text{Some})
\]
\[
\dfrac{\Gamma \vdash e_1 : \tau_1\ \texttt{option} \quad \Gamma \vdash e_2 : \tau \quad \Gamma, x:\tau_1 \vdash e_3 : \tau}
      {\Gamma \vdash \texttt{match}\ e_1\ \texttt{with}\ \texttt{None} \to e_2\ |\ \texttt{Some}\ x \to e_3 : \tau}\ (\text{MatchOpt})
\]

*Semantics:* (note the values $\mathsf{None}$ and $\mathsf{Some}(v)$)

\[
\dfrac{}{\texttt{None} \Downarrow \mathsf{None}}\ (\text{NoneE})
\]
\[
\dfrac{e \Downarrow v}{\texttt{Some}\ e \Downarrow \mathsf{Some}(v)}\ (\text{SomeE})
\]
\[
\dfrac{e_1 \Downarrow \mathsf{None} \quad e_2 \Downarrow v}
      {\texttt{match}\ e_1\ \texttt{with}\ \texttt{None} \to e_2\ |\ \texttt{Some}\ x \to e_3 \Downarrow v}\ (\text{MatchOptNone})
\]
\[
\dfrac{e_1 \Downarrow \mathsf{Some}(v_1) \quad [v_1/x]e_3 \Downarrow v}
      {\texttt{match}\ e_1\ \texttt{with}\ \texttt{None} \to e_2\ |\ \texttt{Some}\ x \to e_3 \Downarrow v}\ (\text{MatchOptSome})
\]

1. Determine a context $\Gamma$ and a type $\tau$ such that the
   following judgment is derivable.  Also provide the derivation.
   You must label all rule instances in your derivation with the
   corresponding rule name.

   \[
   \Gamma \vdash \texttt{match}\ x\ \texttt{with}\ \texttt{None} \to b\ |\ \texttt{Some}\ y \to y = 2 : \tau
   \]

   You will need ~MatchOpt~ above along with the following rules for
   this derivation.

   \[
   \dfrac{(x:\tau) \in \Gamma}{\Gamma \vdash x : \tau}\ (\text{Var})
   \]
   \[
   \dfrac{n\ \text{is an integer literal}}{\Gamma \vdash n : \texttt{int}}\ (\text{IntLit})
   \]
   \[
   \dfrac{\Gamma \vdash e_1 : \tau \quad \Gamma \vdash e_2 : \tau}{\Gamma \vdash e_1 = e_2 : \texttt{bool}}\ (\text{Eq})
   \]

2. Results are like options, except that the analogous "none"
   variant carries data.  The following are some of the syntax,
   typing, and semantic rules for results.

   *Syntax:*

   #+begin_src bnf
     <ty>   ::= ( <ty>, <ty> ) result
     <expr> ::= Ok <expr> | Error <expr>
              | match <expr> with Ok <var> -> <expr> | Error <var> -> <expr>
   #+end_src

   *Typing:*

   \[
   \dfrac{\Gamma \vdash e : \tau_1}{\Gamma \vdash \texttt{Ok}\ e : (\tau_1, \tau_2)\ \texttt{result}}\ (\text{Ok})
   \]
   \[
   \dfrac{\Gamma \vdash e : \tau_2}{\Gamma \vdash \texttt{Error}\ e : (\tau_1, \tau_2)\ \texttt{result}}\ (\text{Error})
   \]

   *Semantics:* (note the values $\mathsf{Ok}(v)$ and $\mathsf{Error}(v)$)

   \[
   \dfrac{e \Downarrow v}{\texttt{Ok}\ e \Downarrow \mathsf{Ok}(v)}\ (\text{OkE})
   \]
   \[
   \dfrac{e \Downarrow v}{\texttt{Error}\ e \Downarrow \mathsf{Error}(v)}\ (\text{ErrorE})
   \]

   In analogy with options, write the typing and semantic rules for
   pattern matching with results.

   Hint: as with options, there should be three rules total.

3. Determine a value $v$ such that the following judgment is
   derivable.  Also provide the derivation.  You must label all rule
   instances in your derivation with the corresponding rule name.

   \[
   \texttt{match}\ \texttt{Error}\ 3\ \texttt{with}\ \texttt{Ok}\ x \to x + 1\ |\ \texttt{Error}\ y \to y + 2 \Downarrow v
   \]

   In addition to the rules you determined in the previous part,
   and ~OkE~ and ~ErrorE~ above, you'll need some of the following
   rules for this derivation.

   \[
   \dfrac{n\ \text{is an integer literal for}\ n}{n \Downarrow n}\ (\text{IntLitE})
   \]
   \[
   \dfrac{e_1 \Downarrow v_1 \quad e_2 \Downarrow v_2 \quad (v = v_1 + v_2)}{e_1 + e_2 \Downarrow v}\ (\text{AddIntE})
   \]
