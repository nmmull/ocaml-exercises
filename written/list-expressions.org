Determine which of the following are valid, type-checking OCaml
~list~ expressions.

1. ~(1 :: 2 :: []) :: (3 :: [4])~
2. ~((1 :: 2) :: []) :: (3 :: [])~
3. ~1 :: 2 :: [3] :: 4 :: [5]~
4. ~1 :: 2 :: [3] @ (4 :: [])~
5. ~(1 :: 2) :: [3] @ (4 :: [])~
