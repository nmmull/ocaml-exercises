\[
\dfrac{\Gamma \vdash e_1 : \texttt{string} \quad \Gamma \vdash e_2 : \texttt{int}}
      {\Gamma \vdash e_1\texttt{.[}e_2\texttt{]} : \texttt{char}}\ (\text{String-Index})
\]

Write down an English sentence which expresses the same thing as the
above typing rule.
