For all derivations, make sure that you label every rule instantiation
with a rule name, and that you do /not/ include side-conditions.

1. Determine a type $\tau$ such that the following typing judgment
   is derivable.  Also provide the derivation.

   \[
   \{ \texttt{f} : \texttt{int -> bool} \} \vdash \texttt{let x = let y = 3 in y + y in f x} : \tau
   \]

2. Determine a type $\tau$ such that the following typing judgment
   is derivable.  Also provide the derivation.

   \[
   \{\} \vdash \texttt{(fun x -> fun y -> y x) (fun x -> x) (fun f -> f 1)} : \tau
   \]
