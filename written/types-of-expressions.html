Types of Expressions

The following is a collection of problems which require you to reason about the types of OCaml expressions.

  1. What is the type of g so that the following expression is well-typed? Can g be given a polymorphic type? Also, what is the type of the following expression? Justify your answer. 

    let rec f x = g x + g (f x) in f

  2. Suppose that h is of type 'a list -> 'a list -> 'a and k is of type 'b -> ('b -> 'b) list. Determine the type of the following expression. Justify your answer. 

    fun x y -> h x (k y)

  3. Determine the smallest context such that the following expression is well-typed. Also determine the type of the expression. 

    let rec f x = f (x + g (f y)) in h (g (x = y)) = f x

  4. Determine the type of the function f. 

    let f =
  let rec g lst =
    match lst with
    | 1 :: 1 :: xs -> h xs
    | [] -> true
    | _ -> false
  and h lst =
    match lst with
    | 0 :: xs -> k xs
    | _ -> false
  and k lst = g lst || h lst
  in k

    Also determine the values of the following expressions:

    • f []
    • f [1]
    • f [1;1;0]
    • f [1;1;1;0;0]
    • f [1;1;1;0;0;1;1;0]
