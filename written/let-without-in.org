Suppose we wanted to eliminate the ~in~ keyword for local
let-expressions in OCaml.  Then we could write

#+begin_example
  let sum_of_squares x y =
    let x_squared = x * x
    let y_squared = y * y
    x_squared + y_squared
#+end_example

This would require something like the following modification to
[[file:an-ocaml-like-grammar.org][the grammar from the previous problem]]
(only the first production rule for ~<e>~ has been modified).

#+begin_src bnf
  <p>  ::= <s> <p> | <s>
  <s>  ::= let <v> = <e>
  <e>  ::= let <v> = <e> <e> | fun <v> -> <e> | <e2>
  <e2> ::= <e2> <e3> | <e3>
  <e3> ::= x | y | z | 0 | 1 | 2 | ( <e> )
  <v>  ::= x | y | z
#+end_src

Demonstrate that the above grammar is ambiguous by determining a
sentence which has multiple parse trees.  Include both parse trees
in your solution.
