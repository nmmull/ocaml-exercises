This is a collection of OCaml programming exercises for the course
*CAS CS 320: Concepts of Programming Languages* at Boston University.
They've been written by [[https://nmmull.github.io][me]] over the last iterations of the course,
with help from [[https://ankushdas.github.io][Ankush Das]] and others.  This page is essentially a
course-specific version of

+ [[https://ocaml.org/exercises][OCaml Exercises]]
+ Exercises from [[https://cs3110.github.io/textbook/cover.html][OCaml Programming: Correct + Efficient + Beautiful]]
+ [[https://projecteuler.net][Project Euler]]

all of which are also valuable resources.
