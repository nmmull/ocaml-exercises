This is a collection of OCaml programming exercises for the course CAS CS 320: Concepts of Programming Languages at Boston University. They've been written by me over the last several years of running the course, with help from Ankush Das. This page is essentially a course specific version of

  • OCaml Exercises
  • Exercises from OCaml Programming: Correct + Efficient + Beautiful
  • Project Euler

all of which are also valuable resources for this course.
