Double List of List

Implement the function 

val of_list_rev: 'a list -> 'a doublelist

so that of_list_rev l is the list l represented as a doublelist in reverse order. Your implementation must be tail recursive.

Examples

let _ = assert (of_list_rev [1;2;3] = Cons (3, 2, Single 1))
let _ = assert (of_list_rev [1;2;3;4] = Cons (4, 3, Cons (2, 1, Nil)))
