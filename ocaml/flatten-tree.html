Flattening Binary Trees

type 'a tree
  = Empty
  | Node of 'a * 'a tree * 'a tree

A binary tree is ordered if, given Node (a, left, right), every element of left is at most a and every element of right is greater than a. Repetitions are allowed.

Implement the function 

val flatten : 'a tree -> 'a list

so that flatten t, given an ordered tree t, the list with the same elements as t sorted in-order.

Example

The function insert is implemented a previous problem. 

let _ = assert (flatten (insert 4 (insert 8 (insert 3 (insert 5 Empty)))) = [3; 4; 5; 8])
