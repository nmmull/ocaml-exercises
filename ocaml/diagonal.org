Fill in the following implementation of the function ~diag~ which,
given ~a : 'a list list~, returns the diagonal of ~a~, assuming ~a~
represents the rows of a valid $m \times n$ matrix, where $m$ and
$n$ are positive.

#+begin_src ocaml
  open List

  let f1 a = ...
  let f2 a = ...

  let rec diag a =
    if is_empty a || is_empty (hd a)
    then []
    else (f1 a) :: diag (f2 a)
#+end_src

Recall that the function ~hd~ returns the first element of a list
and the function ~tl~ returns everything except the first element.
You may use these two functions in your solution, as well as the
function ~map~ for lists, but otherwise you may not use any
functions from the standard library except constructors and
operators.

Determine definitions for ~f1~ and ~f2~ so that ~diag~ is correct.

** Examples

#+begin_src ocaml
  let _ = assert (diag [[1;2;3];[4;5;6];[7;8;9]] = [1;5;9])
#+end_src
