Implement the function
#+begin_src ocaml
  val string_rev : string -> string
#+end_src
so that ~string_rev s~ is the string with the same characters as ~s~
but in reverse order.  Do this without converting the string into a
list of characters.

/Hint:/ Recall that there are no built-in functions for converting
between ~string~ and ~char~. Take a look at the following functions
in the OCaml documentation:

+ ~String.sub~
+ ~String.length~

** Examples

#+begin_src ocaml
  let _ = assert (string_rev "testing" = "gnitset")
  let _ = assert (string_rev "12345" = "54321")
  let _ = assert (string_rev "noon" = "noon")
#+end_src
