Implement the function
#+begin_src ocaml
  val rev : string -> string
#+end_src
so that ~rev s~ is the string with the same characters as ~s~
but in reverse order.  Do this /without/ converting the string into a
list of characters.  See the functions in [[https://nmmull.github.io/stdlib320/stdlib320/Stdlib320/String/index.html][Stdlib320.String]] to get a
sense of the possible approaches.

** Examples

#+begin_src ocaml
  let _ = assert (rev "testing" = "gnitset")
  let _ = assert (rev "12345" = "54321")
  let _ = assert (rev "noon" = "noon")
#+end_src
