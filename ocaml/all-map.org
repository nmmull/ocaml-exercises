Without using any functions from the standard library (except for
basic constructors like ~Some~, ~None~, ~(::)~, and ~[]~), implement
the function
#+begin_src ocaml
  val all_map : ('a -> 'b option) -> 'a list -> 'b list option
#+end_src
which converts a list into an optional list according to the
following specification.

+ If the function ~f~ applied to any element of the list ~l~ is
  ~None~, then ~all_map f l~ is ~None~.
+ Otherwise, ~all_map f l~ is ~Some l'~ where ~l'~ is the same as
  the list ~List.map f l~ but with the ~Some~ constructors removed.

*Your solution must be tail recursive.*

** Examples

#+begin_src ocaml
  let f x = if x > 0 then Some (x * x) else None
  let _ = assert (all_map f [1;2;3] = Some [1;4;9])
  let _ = assert (all_map f [1;-1;3] = None)
  let _ = assert (all_map f [] = Some [])
#+end_src
