Without using any functions from the standard library except for the
usual arithmetic operators, implement the function
#+begin_src ocaml
  val sum_at_k : int list -> int -> int
#+end_src
so that ~sum_at_k l k~ is the result of adding together every
~k~-th element of ~l~, starting from the ~0~-th element.  You may
assume that ~k > 0~.  *Your implementation must be tail recursive.*

** Examples

#+begin_src ocaml
  let _ = assert (sum_at_k [1;2;3;4;5] 2 = 1 + 3 + 5)
  let _ = assert (sum_at_k [1;2;3;4;5] 1 = 1 + 2 + 3 + 4 + 5)
  let _ = assert (sum_at_k [1;2;3;4;5] 10 = 1)
#+end_src
