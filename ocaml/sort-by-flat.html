Ordered Binary Trees

type 'a tree
  = Empty
  | Node of 'a * 'a tree * 'a tree

A binary tree is ordered if, given Node (a, left, right), every element of left is at most a and every element of right is greater than a. Repetitions are allowed.

Using insert and flatten, implement the function 

val sort : 'a list -> 'a list

so that sort l is the elements of l in sorted order. 

let _ = assert (sort [5; 3; 8; 1; 4] = [1; 3; 4; 5; 8])
