Tree Conversion

A binary tree is represented by an ADT with two constructors, a Leaf (representing an empty tree) and a Node2 with a value and two children. 

type 'a tree =
  | Leaf
  | Node2 of 'a * 'a tree * 'a tree

A nonempty (or multiway) tree, on the other hand, is represented by an ADT with a single constructor, a Node with a value and a list of children (a nonempty tree always has a value, though it may have no children). 

type 'a ntree = Node of 'a * 'a ntree list

Implement the function 

val ntree_of_tree : 'a tree -> 'a ntree option

so that ntree_of_tree t is None if t is empty (i.e., it's just a Leaf) and, otherwise, is Some t' where t' is a representation of t as a nonempty tree. In particular, each child of a Node2 that is a Leaf should simply not appear in the list of children of the corresponding Node.

Examples

let t1 : int tree =
  Node2
    ( 1
    , Node2 (2, Leaf, Leaf)
    , Node2 (3, Leaf, Node2 (4, Leaf, Leaf))
    )
let _ = assert (ntree_of_tree t1 =
    Some (Node (1, [Node (2, []); Node (3, [Node (4, [])])])))
let _ = assert (ntree_of_tree (Node2 (1, Leaf, Leaf)) = Some (Node (1, [])))
let _ = assert (ntree_of_tree Leaf = None)
