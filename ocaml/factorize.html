Factorize

Implement the function 

val factorize : int -> (int * int) list

so that factorize n computes the prime factorization of n and returns it as a list of pairs of a prime factor and its corresponding exponent. That is, if n can be written as \(p_1^{e_1} \cdot p_2^{e_2} \cdots p_k^{e_k}\), then factorize n should be [(p1, e1); (p2, e2); ...; (pk, ek)], with the primes appearing in increasing order. For example, factorize 360 should be [(2,3);(3,2);(5,1)], since \(360 = 2^3 \cdot 3^2 \cdot 5^1\). For input 1, the output should be the empty list. You may assume the input is positive.

Examples

let _ = assert (factorize 1 = [])
let _ = assert (factorize 19 = [(19,1)])
let _ = assert (factorize 16 = [(2,4)])
let _ = assert (factorize 360 = [(2,3);(3,2);(5,1)])
