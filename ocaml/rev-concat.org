Implement the function
#+begin_src ocaml
  val rev_concat : 'a list list -> 'a list
#+end_src
so that ~rev_concat ls~ is ~List.rev (List.concat ls)~ but does not
use the function ~List.rev~.  Your implementation must be tail
recursive.

** Examples

#+begin_src ocaml
  let _ = assert (rev_concat [[1; 2]; [3; 4]; [5]] = [5; 4; 3; 2; 1])
#+end_src
