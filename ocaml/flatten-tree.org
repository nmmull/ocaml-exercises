#+begin_src ocaml
  type 'a tree
    = Empty
    | Node of 'a * 'a tree * 'a tree
#+end_src

A binary tree is /ordered/ if, given ~Node (a, left, right)~, every
element of ~left~ is at most ~a~ and every element of ~right~ is
greater than ~a~.  Repetitions are allowed.

Implement the function
#+begin_src ocaml
  val flatten : 'a tree -> 'a list
#+end_src
so that ~flatten t~, given an ordered tree ~t~, the list with the same
elements as ~t~ sorted in-order.

** Example

The function ~insert~ is implemented a [[file:binary-tree-insert.org][previous problem]].

#+begin_src ocaml
  let _ = assert (flatten (insert 4 (insert 8 (insert 3 (insert 5 Empty)))) = [3; 4; 5; 8])
#+end_src
