Grouping

A list of integers l is valid if it satisfies the following properties:

  • every 0 appearing in l must have nonzero integers to the left and right of it of opposite signs
  • for every nonzero entry x of l, if there is an entry adjacent to x, then it must be the same sign as x or 0

Lists which do not satisfy these properties are invalid. So, for example 

let l1 = [1;2;3;0;-1;-2;-3;0;1]

is valid, whereas 

let l1 = [1;2;3;0;1;2;3;0;1]
let l2 = [0;1;2;3]
let l3 = [1;0;0;-1]

are invalid.

Intuitively, a list is valid if it is made of nonempty sublists of same-sign integers, switching between positive and negative, separated by zeros (see how much nicer the formal description is?).

The grouping of a valid list of integers is a list of integer lists which groups together the adjacent nonzero entries (and drops the zero entries). So, for example, 

let l1_grouping = [[1;2;3];[-1;-2;-3];[1]]

is the grouping for the valid list l1 above.

Implement the function 

val group : int list -> int list list option

so that group l, given a list of integers l, returns the grouping of l given l is valid. The grouping should be returned as an option, where the output is None if the list is invalid.

Examples

let _ = assert (group [1;2;3;0;-1;-2;-3;0;1] = Some [[1;2;3];[-1;-2;-3];[1]])
let _ = assert (group [1;2;3;0;1;2;3;0;1] = None)
let _ = assert (group [0;1;2;3] = None)
let _ = assert (group [1;0;0;-1] = None)
