Implement the function
#+begin_src ocaml
  val prime : int -> int
#+end_src
so that ~prime~ $n$ is the $n$^{th} [[https://en.wikipedia.org/wiki/Prime_number][prime number]].  The behavior of
this function is undefined if $n$ is negative.

** Examples

#+begin_src ocaml
  let _ = assert (prime 0 = 2)
  let _ = assert (prime 1 = 3)
  let _ = assert (prime 2 = 5)
  let _ = assert (prime 500 = 3581)
#+end_src
