Using Euclid's algorithm, implement the function
#+begin_src ocaml
  val gcd : int -> int -> int
#+end_src
so that ~gcd m n~ is the [[https://en.wikipedia.org/wiki/Greatest_common_divisor][greatest common divisor]] of ~m~ and ~n~.

** Examples

#+begin_src ocaml
  let _ = assert (gcd 12 8 = 4)
  let _ = assert (gcd 17 5 = 1)
  let _ = assert (gcd 0 9 = 9)
  let _ = assert (gcd 48 18 = 6)
  let _ = assert (gcd 100 75 = 25)
#+end_src
