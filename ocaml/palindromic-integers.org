An integer is /palindromic/ if it's the same as itself with its digits
written in reverse order.  For example ~12321~ is a palindromic
integer.  Note that negative numbers are not palindromic.

Implement the function
#+begin_src ocaml
  val is_palindromic : int -> bool
#+end_src
so that ~is_palindromic n~ is ~true~ if and only if ~n~ is
palindromic.

** Examples

#+begin_src ocaml
  let _ = assert (is_palindromic 0)
  let _ = assert (is_palindromic 7)
  let _ = assert (is_palindromic 12321)
  let _ = assert (not (is_palindromic 12345))
  let _ = assert (not (is_palindromic (-121)))
#+end_src
