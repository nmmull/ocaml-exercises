Without using any functions from the standard library except for the
usual arithmetic and comparison operators, implement the function
#+begin_src ocaml
  val split : int -> int list -> int list * int list
#+end_src
so that ~split n l~ is a pair of lists such that the first list
contains all elements of ~l~ less than ~n~ and the second list
contains all elements of ~l~ greater than or equal to ~n~.  You must
maintain the relative order of elements.

** Examples

#+begin_src ocaml
  let _ = assert (split 4 [1;3;5;2;4;6] = ([1;3;2], [5;4;6]))
  let _ = assert (split 0 [1;2;3] = ([], [1;2;3]))
#+end_src
