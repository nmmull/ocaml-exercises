Splits

A split of a list l is a pair of lists l1 and l2 such that l1 concatenated with l2 is l (i.e., l = l1 @ l2). For example ([], [1;2;3]) and ([1;2], [3]) are splits of [1;2;3].

Implement the function 

val splits : 'a list -> ('a list * 'a list) list

so that splits l generates all possible splits of l. You should not use any library function for this problem; if you'd like to use a library function, define it yourself first.

Examples

let _ = assert (splits [] = [([], [])])
let _ = assert (List.length (splits [1;2;3]) = 4)
let _ = assert (List.mem ([], [1;2;3]) (splits [1;2;3]))
let _ = assert (List.mem ([1], [2;3]) (splits [1;2;3]))
let _ = assert (List.mem ([1;2], [3]) (splits [1;2;3]))
let _ = assert (List.mem ([1;2;3], []) (splits [1;2;3]))
