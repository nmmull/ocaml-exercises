A /split/ of a list ~l~ is a pair of lists ~l1~ and ~l2~ such ~l1 @ l2 = l~.

Implement the function
#+begin_src ocaml
  val splits : 'a list -> ('a list * 'a list) list
#+end_src
so that ~splits l~ is the list of all possible splits of ~l~, in order
of increase length of the left list in the split.

** Examples

#+begin_src ocaml
  let _ = assert (splits [] = [([], [])])
  let _ = assert (splits [1;2;3] =
      [([], [1;2;3]); ([1], [2;3]); ([1;2], [3]); ([1;2;3], [])])
#+end_src
