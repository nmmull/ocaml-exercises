Total Stopping Time Records

In this problem, we define a different sequence based on the collatz function. The number collatz \(n\) is sometimes called the total stopping time of \(n\). We say that \(n\) has a total stopping time record if its total stopping time is greater than that of any previous number. That is, \(n\) has a total stopping time record if collatz \(m\) \(<\) collatz \(n\) for all \(m\) satisfying \(1 \leq m < n\).

Implement the function 

val tst_records : int -> int

so that tst_records \(n\) is the \(n\)th smallest number with a total stopping time record.

Examples

let _ = assert (tst_records 0 = 1)
let _ = assert (tst_records 1 = 2)
let _ = assert (tst_records 2 = 3)
let _ = assert (tst_records 3 = 6)
let _ = assert (tst_records 4 = 7)
let _ = assert (tst_records 5 = 9)
let _ = assert (tst_records 6 = 18)
let _ = assert (tst_records 7 = 25)
