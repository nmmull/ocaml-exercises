Deepest Parentheses

type paren = Op | Cl

Implement the function 

val deepest_parens : paren list -> int

so that deepest_parens ps is the index of (the left parenthesis of) the leftmost deepest pair of parentheses in ps. The behavior of the function is undefined if ps does not represent a balanced set of parentheses. Try to do so using List.fold_left.

Challenge worth nothing: Think about how your algorithm changes if we consider the rightmost deepest pair.

Examples

let _ = assert (deepest_parens [Op;Cl] = 0)                   (* () *)
let _ = assert (deepest_parens [Op;Cl;Op;Op;Cl;Cl] = 3)       (* ()(()) *)
let _ = assert (deepest_parens [Op;Op;Cl;Op;Cl;Cl] = 1)       (* (()()) *)
let _ = assert (deepest_parens [Op;Op;Cl;Op;Op;Cl;Cl;Cl] = 4) (* (()(())) *)
